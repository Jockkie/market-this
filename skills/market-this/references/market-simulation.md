# Market simulation with MiroFish (optional)

MiroFish (https://mirofish.my) is a swarm simulation engine. It turns source material into a group of simulated agents who react to it over several rounds, in social-media-like settings, and writes a prediction report. It lists market simulation (launches, pricing, market entry) as a use case. It is a web app: you upload PDF, MD or TXT files and add a simulation prompt.

A simulation is a stress test of ideas, not market research. It shows likely objections and reactions to explore; it never replaces real customer conversations or sales numbers.

## When to offer it

- Phase 1 to 3: testing whether a segment reacts to the problem framing
- Phase 3: comparing two price points or two offers
- Phase 4: comparing two positionings or headlines
- Before a launch: stress-testing the launch message for objections

## How to prepare a run

1. Write a short source document (MD) from the dossier: product, ICP, alternatives, the variants to compare, price. No personal data, no confidential numbers the user does not want to upload.
2. Write the simulation prompt, for example:
   > Simulate how <ICP> react to these two offers over five rounds on a professional social network and a forum. Report: first reactions, main objections, which variant gets more serious interest and why, and which questions remain.
3. Tell the user what will be uploaded and where, and get consent. Check the current pricing on the MiroFish site and state it before they start.
4. The user runs it in the MiroFish web app and pastes or uploads the report.

## Reading the result

- Pull out objections and questions; turn each into a line in the FAQ, the offer or the proof plan.
- Treat preference between variants as a hypothesis to test with real people (five conversations or a small paid test).
- Record in the dossier under `simulations`: date, variants, main findings, label `inferred`.
